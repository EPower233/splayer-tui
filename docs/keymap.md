# 键位表 v2（vim 风格，草案，2026-11-08）

v1 是照抄 SPlayer-Next 的 Ctrl 组合键，已作废。v2 的思路：

- **全局键只留几个**，其余全部跟着"当前焦点所在的窗口"走。
- **同一个键在不同窗口做相似但不完全相同的事**，比如 `dd` 在播放列表里是移出队列，在自己的歌单里是从歌单删掉。
- 尽量符合 vim 的直觉：`hjkl` 移动、`/` 搜索、`n` `N` 跳下一个 / 上一个结果、`y` 复制、`p` 粘贴、`dd` 删除、`u` 撤销、`v` 多选、数字是次数（`3dd`）、`g` 开头是"跳转"。
- Next 里每个有快捷键的动作，这里都有对应的键（见文末对照），只是键换成了 vim 习惯。所有键都能在配置文件里改。

写法：`^` 是 Ctrl，`␣` 是空格，`⏎` 是回车。

## 全局（任何窗口都有效）

| 键 | 动作 |
|---|---|
| `␣` | 播放 / 暂停 |
| `<` `>` | 上一首 / 下一首 |
| `-` `=` | 音量减 / 加 |
| `:` | 命令行：输入动作名执行，比如 `:q` 退出、`:set 逐字歌词` 改设置；对应 Next 搜索框里的"/ 命令模式" |
| `^w` 再按 `h` `j` `k` `l` | 在窗口之间跳（侧栏、内容、播放栏、播放列表）；`Tab` 也能按顺序轮着切 |
| `?` | 当前窗口的键位帮助 |
| `^c` | 退出（保险用） |

## 窗口里的键：同一个键，意思随窗口变

### 移动和查找（所有窗口通用）

`j` `k` 上下，`h` `l` 左右（在列表里 `h` 是返回上一级，`l` 是进入），`gg` `G` 到顶 / 到底，`^d` `^u` 翻半页，`PgDn` `PgUp` 翻整页（vim 的 `^b` 是 tmux 的默认前缀键，不用），`/` 在当前窗口里搜索 / 筛选，`n` `N` 跳下一个 / 上一个结果，`Esc` 取消，`q` 关闭当前弹窗或面板。

### 跳转（`g` 开头）

`gh` 首页、`gm` 音乐库、`ga` 艺术家、`gb` 专辑、`gf` 文件夹、`gs` 统计、`gl` 我喜欢的音乐、`gc` 我的收藏、`gy` 我的云盘、`gt` 媒体源、`gr` 播放历史、`gp` 全屏播放页、`gq` 播放列表。

侧栏每项旁边标的就是它的跳转键。数字留给 vim 的"次数"，不再用来跳侧栏。

| `*` | 喜欢 / 取消喜欢 | 同左 | 同左 | 收藏歌单 / 专辑、关注歌手 | — |

### 播放栏、全屏播放页

| 键 | 动作 |
|---|---|
| `h` `l` | 快退 / 快进 5 秒（在时间轴上左右移动） |
| `H` `L` | 快退 / 快进 30 秒 |
| `j` `k` | 全屏页里移到上 / 下一句歌词，并跳到那里播放 |
| `s` | 播放模式：顺序 / 随机 / 心动（私人 FM 时是"不喜欢"） |
| `r` | 循环模式 |
| `*` | 喜欢正在播放的歌 |
| `⏎` | 在播放栏上按：打开全屏播放页 |
| `q` | 在全屏页里按：收起 |
| `[` `]` | 歌词提前 / 延后 |
| `o` | 歌词设置弹窗（里面 `w` 逐字、`t` 翻译、`r` 音译） |

### 设置页

`j` `k` 选项目，`h` `l` 改值，`⏎` 进入子页，`/` 搜索设置项，`q` 关闭。

## 防冲突的规矩

1. **全局键只有上面那 7 组**，任何窗口都不能拿它们做别的事。
2. **一个窗口之内，一个键只做一件事。** 不同窗口可以复用同一个键，但意思要相近。
3. **只有焦点所在的窗口亮出按键提示**，其他窗口的提示变暗。屏幕上同时看到两个 `dd` 时，亮的那个才是现在按了会生效的。
4. **不靠大小写区分毫不相干的两件事。** 大写只用来表示"同一件事的加强版"，比如 `a` / `A`、`h` / `H`，这也是 vim 的习惯。
5. **键位表在代码里是数据**：全局一张、每个窗口一张。单元测试检查每个窗口的"全局 + 本窗口"没有重复。用户改了配置也要过这个检查，有冲突就拒绝加载并指出冲突在哪。
6. **不用会被终端或 tmux 截走的组合**：`^a` `^b` `^z` `^\`。

## 和 Next 快捷键的对照

| Next 的动作 | Next 默认键 | 这里 |
|---|---|---|
| 播放 / 暂停 | `Space` | `␣` |
| 上一首 / 下一首 | `Ctrl+←` / `Ctrl+→` | `<` / `>` |
| 快退 / 快进 | `Shift+←` / `Shift+→` | 播放栏或全屏页里的 `h` / `l` |
| 音量加 / 减 | `Ctrl+↑` / `Ctrl+↓` | `=` / `-` |
| 循环模式 | `Ctrl+R` | 播放栏里的 `r` |
| 随机模式 | `Ctrl+S` | 播放栏里的 `s` |
| 打开 / 收起播放器 | `Ctrl+Enter` / `Ctrl+Esc` | `gp` / 全屏页里的 `q` |
| 播放列表 | `Ctrl+P` | `gq` |
| 打开搜索 | `Ctrl+F` | `:` 命令行（输入关键词就是搜索） |
| 页内搜索 | `/` | `/` |
| 设置 | `Ctrl+,` | `:set` 或 `:settings` |

## 还没想好的

- 全局键要不要再加一个快进快退（现在只在播放栏和全屏页里有）。
- `g` 开头的跳转键，是用英文首字母，还是照侧栏顺序编号（`g1` `g2`…）。
- 习惯 Next 键位的人，要不要提供一套"SPlayer-Next 键位"预设，一键切换。
