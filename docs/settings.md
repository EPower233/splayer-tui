# 设置项对照：SPlayer-Next → 终端版

来源：SPlayer-Next `src/settings/categories/*.ts`（提交 a8716df），共 231 项，中文名取自它的 `zh-CN.json`。原则是**能保留的尽量保留**：功能还没做的，设置项跟着功能以后加，不算砍掉。

**标记**
- ✅ 保留：意思和 SPlayer 一样
- 🔁 换成终端版：目的一样，做法换成终端能做到的
- ⏳ 以后：对应的功能不在 v0.1，功能做了设置就跟着来
- ✗ 不适用：终端里做不到或没有意义，写明原因

**怎么设置**：所有设置都存在一个 TOML 配置文件里，程序里也有一个设置页，分类和 SPlayer 一样，改了立即生效、可以预览（学 ypm）。默认值照 SPlayer，例外见文末。
